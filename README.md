# 🐍 Google Play Arcade: Husnain Edition

A fully-featured, polished Snake game built from scratch — smooth gliding movement, a real progression system, a live global leaderboard, and full support for **PC, mobile, and TV remotes**.

**🎮 Play it now → [minahilobaid-lgtm.github.io/snake-game](https://minahilobaid-lgtm.github.io/snake-game/)**

---

## ✨ Features

- **Smooth, gliding movement** — not the old block-by-block snake, real interpolated animation
- **3 map sizes** (Small / Medium / Large) and **4 difficulty levels** (Easy → Insane)
- **Combo scoring system** — chain fruit pickups for bonus points
- **Shop & progression** — unlock new snake skins, grid themes, and boundary colors by hitting score milestones, plus an exclusive achievement skin for clearing every map size
- **Live global leaderboard** — real-time scores from every player worldwide, powered by Firebase
- **Built-in anti-cheat** — score integrity checks to keep the leaderboard legit
- **Fully responsive** — the board scales itself to fit any screen, from a small phone to a huge 4K TV
- **Sound effects & background music**, with volume/mute controls

## 🕹️ Controls

| Device | Move | Select / Confirm | Pause |
|---|---|---|---|
| **PC** | Arrow keys / WASD | Enter | P |
| **Mobile** | Swipe anywhere on screen | Tap | Pause button |
| **Smart TV remote** | D-pad | OK (center button) | OK / P |

On a TV, the D-pad also navigates menus and the shop with a visible highlight — no mouse needed.

## 🛠️ Built With

- Vanilla HTML, CSS, and JavaScript (Canvas 2D rendering)
- [Firebase Firestore](https://firebase.google.com/) for the real-time global leaderboard
